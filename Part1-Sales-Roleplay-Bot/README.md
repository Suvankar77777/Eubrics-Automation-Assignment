# 🤖 Sales Roleplay AI

An AI-powered Sales Roleplay Assistant built using Streamlit and Ollama (Gemma 3).

## Features

- AI-powered customer simulation
- Multiple sales scenarios
- Customer personas
- Difficulty levels
- Conversation memory
- Sales performance evaluation
- Download conversation history
- Modern Streamlit UI

---

## Tech Stack

- Python
- Streamlit
- Ollama
- Gemma 3

---

## Installation

Clone the repository:

```bash
git clone https://github.com/Suvankar77777/Eubrics-Automation-Assignment/Part1-Sales-Roleplay-Bot.git
```

Move into the project:

```bash
cd Part1-Sales-Roleplay-Bot
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it.

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Ollama:

```bash
ollama run gemma3:latest
```

Run Streamlit:

```bash
streamlit run app.py
```
